# 柒号收银系统 — 品牌化提示文案规范

## 设计原则
1. **口语化**：让人读起来像同事说的话，不用祈使句堆砌，不用生硬的机器用语
2. **有呼吸感**：短句 ≤15 字，不堆砌信息，上下文强相关
3. **建设性**：错误提示不只说失败，还要说明原因 + 你能做什么
4. **克制**：成功提示点到即止，不用过度渲染

---

## 收银场景 20 条核心提示文案

| 场景 | 原来文案 | 口语化文案 |
|---|---|---|
| 保存成功 | 数据保存成功 | 存好了 ✓ |
| 库存不足 | 库存数量不足 | 只剩 X 件，要不要调拨？ |
| 会员不存在 | 会员信息查询失败 | 没找到这个会员，要新建吗？ |
| 会员积分不足 | 会员积分不足以抵扣 | 还差 X 积分，要换其他支付方式吗？ |
| 订单作废确认 | 确认要作废该订单？ | 要作废这张单吗？钱会原路退回。 |
| 券码无效 | 优惠券码无效或已使用 | 券对不上，再确认一下？ |
| 优惠券已过期 | 优惠券已过期 | 这张券过期了，换一张？ |
| 网络异常 | 网络连接失败 | 网络有点不稳定，刷新试试？ |
| 请求超时 | 请求超时，请稍后重试 | 响应时间有点长，再试一次？ |
| 退款成功 | 退款操作已完成 | 已退 ¥X.XX，预计 1-3 天到账 |
| 交班日结完成 | 日结操作成功 | 今天辛苦了！收银 ¥X.XX |
| 沽清标记 | 商品已标记为缺货 | 已售罄，顾客端不会再看到 |
| 库存预警 | 库存低于安全阈值 | X 备货不足，预计 X 天后断货 |
| 商品下架 | 商品已下架 | 已隐藏，前台不会展示 |
| 支付失败 | 第三方支付渠道异常 | 支付没成功，换种方式？ |
| 登录失败 | 账号或密码错误 | 账号密码不对，再试一次？ |
| 打印失败 | 打印机连接异常 | 小票机没连上，重启试试？ |
| 清台确认 | 确认要清空该桌台？ | 这张台要清掉吗？已下单的顾客会受影响 |
| 折扣超限 | 折扣率超出上限 | 折扣最多 X%，要调整吗？ |
| 现金实付不足 | 实付金额小于应付金额 | 还差 ¥X.XX，补一下？ |

## 错误提示设计模板
```
[发生了啥] + [因为什么] + [你能做什么]
```
示例：
- ✘ 错误：网络连接失败
- ✔ 优化：网络有点不够稳，刷新一下试试？

## 成功提示设计模板
```
[完成了啥] + [可选：下一个动作]
```
示例：
- ✘ 成功：订单保存成功，您可以继续其他操作
- ✔ 优化：订单已保存，要继续下单吗？

## 确认弹窗设计模板
```
[要做的事] + [后果/影响] + [可选：撤销提示]
```
示例：
- ✘ 确认：您确定要执行此操作吗？
- ✔ 优化：要删除这个商品吗？删除后就找不回来了。
